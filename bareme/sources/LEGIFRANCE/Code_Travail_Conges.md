# Source CODE DU TRAVAIL — Congés et absences

**Type** : Code du travail  
**Référence** : Livre III, Titre IV  
**URL officielle** : https://www.legifrance.gouv.fr/codes/id/LEGITEXT000006072050/  
**Validé par KDS le** : 10/02/2026  

## Périmètre

Congés payés, congés maternité/paternité/adoption, événements familiaux.

## Articles clés

### Congés payés
- **Art. L3141-1 à L3141-33** : Acquisition, durée (5 semaines), prise, indemnisation

### Maternité
- **Art. L1225-17 à L1225-28** : Durée (16 semaines minimum), protection, droits

### Paternité et accueil de l'enfant
- **Art. L1225-35 à L1225-38** : Durée (25 jours + 7 jours obligatoires)

### Adoption
- **Art. L1225-37** : Durée variable selon nombre d'enfants

### Événements familiaux
- **Art. L3142-1 à L3142-5** : Mariage, PACS, décès, etc.
