Démarrage rapide (2 minutes)

Navigation dans l'application

Recherche avancée

La recherche est l'outil le plus puissant de l'application. Elle filtre en temps réel les Essentiels et les tuiles chapitres.

Exemple 1
Recherche : SMIC
→ Affiche SMIC horaire, SMIC mensuel, tuile "Rémunération minimale"
Exemple 2
Recherche : paternité
→ Affiche le chapitre "Congés légaux" avec durées congé paternité
Exemple 3
Recherche : véhicule
→ Affiche "Avantages en nature : Véhicule" avec barèmes km

💡 Astuces recherche

  • ✅ Tapez des mots-clés simples (pas de phrases complètes)
  • ✅ Fonctionne avec les acronymes (PAS, PMSS, RGDU, CSG, etc.)
  • ✅ Insensible à la casse (smic = SMIC = Smic)
  • ✅ Cherche dans les titres ET descriptions
  • ❌ Ne cherche pas dans le contenu détaillé des tiroirs (utilisez Ctrl+F du navigateur pour ça)

Simulateurs et calculateurs

L'application propose plusieurs simulateurs pratiques pour vos calculs quotidiens.

🎯 RGDU (réduction Fillon)

Accès : Bouton "RGDU" en haut à droite

Calcule : Le coefficient de réduction générale des cotisations patronales

Champs requis : Rémunération brute, heures payées, heures travaillées

💰 Prélèvement à la source

Accès : Bouton "Simulateurs" → PAS

Calcule : Le montant du PAS selon le taux et le net imposable

Champs requis : Net imposable, taux de PAS (ou grille taux neutre)

📊 Net imposable

Accès : Bouton "Simulateurs" → Net imposable

Calcule : Le net imposable à partir du brut

Champs requis : Salaire brut, cotisations salariales déductibles

⏰ Heures supplémentaires

Accès : Bouton "Simulateurs" → Heures sup

Calcule : Majorations 25% et 50% + exonération fiscale

Champs requis : Taux horaire brut, nombre d'heures sup

💡 Conseils pour les simulateurs

  • ✅ Vérifiez bien l'assiette demandée (brut vs net imposable vs net à payer)
  • ✅ Les résultats sont indicatifs — validez toujours dans votre logiciel de paie
  • ✅ Utilisez "Copier le résumé" pour coller le résultat dans un email ou ticket
  • ⚠️ Les simulateurs ne prennent pas en compte les spécificités conventionnelles

Sources & fiabilité des données

100% des chapitres sont documentés avec leurs sources officielles.

📋 Badges sources

Depuis la version 3.0, chaque donnée clé (section Essentiels) affiche un badge source :

📄 Décret ministériel 📄 BOSS 📄 Code du travail

Au hover : Tooltip avec organisme et référence précise

Au clic : Ouverture de la fiche source complète

📚 Organismes de référence

  • BOSS (Bulletin Officiel Sécurité Sociale) — boss.gouv.fr
  • URSSAF — urssaf.fr
  • Légifrance (Code du travail, Code SS) — legifrance.gouv.fr
  • DGFiP (BOFiP pour barèmes fiscaux) — bofip.impots.gouv.fr

🔍 Accéder aux sources complètes

Toutes les fiches sources sont disponibles dans le dossier sources/ :

  • 📁 sources/BOSS/ — Fiches BOSS détaillées
  • 📁 sources/LEGIFRANCE/ — Références légales
  • 📁 sources/DGFIP/ — Barèmes fiscaux
  • 📁 sources/AUTRES/ — Sources complémentaires

Chaque fiche contient : titre, organisme, référence, URL officielle, date de vérification, et explications détaillées.

Export PDF

📄 Télécharger le mémo complet

  1. Cliquez sur le bouton "Télécharger PDF" en bas de page (ou dans le menu)
  2. Une nouvelle page s'ouvre avec une mise en page optimisée pour l'impression
  3. Dans votre navigateur : Ctrl+P (Windows) ou Cmd+P (Mac)
  4. Dans la fenêtre d'impression : choisir "Enregistrer au format PDF"
  5. Sélectionner le dossier de destination et enregistrer

📋 Imprimer une tuile spécifique

Vous n'avez besoin que d'un chapitre ?

  1. Ouvrez la tuile souhaitée (ex : "Heures supplémentaires")
  2. Dans le tiroir latéral, cliquez sur "Imprimer cette tuile"
  3. Suivez les mêmes étapes que ci-dessus pour enregistrer en PDF

💡 Conseils export

  • ✅ Le PDF inclut toutes les données + sources
  • ✅ Mise en page professionnelle avec en-tête Koesio
  • ✅ Table des matières cliquable
  • ⚠️ Les simulateurs ne sont pas inclus (seulement les valeurs de référence)

Questions fréquentes (FAQ)

Les données sont-elles à jour pour 2026 ?

Oui, toutes les données ont été vérifiées au 10 février 2026. La date de dernière mise à jour est visible en haut de la page d'accueil. Des révisions mensuelles sont prévues.

Puis-je me fier aux résultats des simulateurs ?

Les simulateurs sont indicatifs et basés sur les paramètres légaux interprofessionnels. Ils ne remplacent pas votre logiciel de paie ni la validation par un expert-comptable. Vérifiez toujours les spécificités de votre convention collective.

Que signifie le badge "📄 Source" ?

C'est un nouveau badge (v3) qui garantit la traçabilité de chaque donnée. Au hover, il affiche l'organisme et la référence exacte. Au clic, il ouvre la fiche source complète avec l'URL officielle.

Comment signaler une erreur ?

Si vous identifiez une erreur ou une donnée obsolète, consultez la section À propos pour accéder aux informations de contact ou au dossier sources/ pour vérifier vous-même la source.

L'application fonctionne-t-elle hors ligne ?

Non, l'application nécessite une connexion pour charger les fichiers JavaScript et CSS. Cependant, vous pouvez télécharger le PDF pour consulter les données hors ligne.

Sur quels navigateurs fonctionne l'application ?

Tous les navigateurs modernes sont supportés : Chrome, Firefox, Edge, Safari (versions récentes). L'application est également responsive et fonctionne sur mobile et tablette.
